# 🛰️ Voxel

> Physics-Guided Band Selection and Hybrid CNN-ViT Fusion for Satellite Earth Observation

Voxel is a research project focused on reducing the dimensionality of hyperspectral satellite imagery while preserving high classification performance. The framework combines physics-guided spectral grouping, metaheuristic optimization, and deep learning to create an efficient and interpretable Earth Observation pipeline.

---

## 🚀 Features

- Physics-guided spectral grouping
- Intelligent hyperspectral band selection
- Hybrid CNN + Vision Transformer (ViT)
- Explainable AI (SHAP)
- Land Cover Classification
- Reduced computational cost
- Green AI approach
- Support for hyperspectral benchmark datasets

---

## 📌 Objectives

- Reduce redundant spectral bands
- Preserve classification accuracy
- Improve computational efficiency
- Develop an intelligent band selection framework
- Increase model interpretability using Explainable AI
- Evaluate on benchmark hyperspectral datasets
